<h1 align="center">train_waybills</h1>
<h3 align="center">Serwis imitujacy zamawianie i przewóz wagonów towarowych na kolei między różnymi firmami.</h3>
<p>Składa się z trzech obszarów:
<ol>
  <li>Obszar ogólnodostępny
    <div>Można w nim zarejestrować firmę lub zalogować się do serwisu.</div>
  </li>
  <li>Obszar administracyjny
    <div>Można w nim dodawać, usuwać lub modyfikować: wagony kolejowe, zamówienia, firmy, pracowników i punkty ładunkowe.<br>Posiada możliwość wyświetlenia szczegółowych informacji na temat zamówienia.</div>
  </li>
    <li>Obszar firmy
    <div>Można w nim dodawać, usuwać lub modyfikować zamówienia.</div>
  </li>
    </li>
    <li>Obszar pracownika
    <div>Zawiera wyszukiwarkę wagonów, gdzie po wpisaniu numeru wagonu zostają wyświetlone informacje o statusie wagonu lub punktu docelowego. Zmiana statusu wagonu wymaga potwierdzenia, np.: po przez załadowanie wagonu.</div>
  </li>
</ol>
</p>
